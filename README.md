# Jitter-Themes
Jitter-Shadow: A matte-black, deep graphite &amp; crimson (#E11D2E) visual suite for Linux XFCE &amp; ARM64 cyberdecks (uConsole/Hackberry Pi). Includes custom GTK2/3 themes, panel CSS overrides, 720x720 Conky telemetry HUDs, waveform Plymouth boot splashes &amp; xwinwrap/mpv live wallpaper scripts. Tested on Kali ARM64, Debian Jitter OS, Fedora &amp; Pop!_OS.
